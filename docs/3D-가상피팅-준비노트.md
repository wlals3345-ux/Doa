# DOA 3D 가상 피팅 준비 노트

작성일: 2026-10-13

## 현재 결정

상품과 인체 데이터를 더 수집한 뒤 구현을 재개합니다. 현재 사이트의 마네킹 피팅 화면, 메뉴, 상품 상세 진입 버튼은 제거했습니다. 이전 실험 코드는 Git 이력의 f050370 커밋에서 확인할 수 있습니다.

## 원하는 기능

사람 형태의 3D 모델에 소비자가 설정한 체형을 반영하고, 여러 상품을 조합해 입힌 뒤 360도로 확인합니다. 키·몸무게뿐 아니라 어깨·가슴·허리·엉덩이 치수도 고려합니다. 키와 몸무게만으로 실제 체형을 정확히 복원할 수는 없습니다.

## 3D 데이터는 무엇인가요?

인체와 옷의 입체 모양(메시), 피부와 원단의 표면(텍스처·재질), 체형 변화 정보(모프), 필요하면 관절 정보(리깅)를 담은 파일입니다. 웹에서 사용할 때는 GLB/glTF 등의 형식으로 준비합니다.

## 1. 사람 모델 제작

MakeHuman 같은 인체 제작 도구에서 기본 인체를 만들고 얼굴·신체 비율을 조절합니다. 머리카락·눈·피부·손발을 다듬고, 같은 모델에 체형 변화 데이터를 만들어 웹의 슬라이더와 연결합니다. 표준 자세와 단위, 의상과 공유할 기준 체형을 먼저 정해야 합니다.

- 필요한 자료: 원하는 외모와 헤어 참고, 기본 체형, 체형 조절 범위.
- 공식 자료: [MakeHuman 인체 조절](https://static.makehumancommunity.org/makehuman/docs/modeling_the_body.html), [체형 변형 데이터](https://static.makehumancommunity.org/assets/creatingassets/maketarget/targets.html).

## 2. 상품별 의류 제작

앞·뒤·소매 등 옷의 패턴을 만들고 봉합한 뒤 인체에 입혀 주름과 떨어지는 모양을 계산합니다. Marvelous Designer 등의 의류 제작 도구에서 작업할 수 있습니다. 봉제선·지퍼·단추·원단 재질을 추가하고 웹용으로 최적화합니다.

- 필요한 자료: 상품 앞·뒤·옆 사진, 디테일 사진, 사이즈별 실측표, 소재·신축성 정보, 가능하면 실제 패턴.
- 현재 AI 생성 상품 사진에는 실제 패턴과 뒷면 정보가 없습니다. 보이지 않는 부분은 별도로 디자인해야 하며, 정확한 실물 복원으로 설명할 수 없습니다.
- 공식 자료: [의류 시뮬레이션](https://support.marvelousdesigner.com/hc/en-us/articles/47358232630937-Simulation), [GLB 내보내기](https://support.marvelousdesigner.com/hc/en-us/articles/55686813557913-glTG-2-0-glTF-GLB-File-ver-2026-0).

## 3. 체형과 의상 연결

몸이 변하면 옷도 함께 변하도록 의상별 변형 데이터를 준비합니다. 여러 체형에서 몸과 옷이 뚫리거나 겹치지 않는지 확인합니다. 상의·바지·아우터를 겹쳐 입는 조합도 별도로 검증해야 합니다. 준비된 주름을 보여주는 방식과 실시간 물리 시뮬레이션은 서로 다른 구현입니다.

## 도아의 권장 제작 순서

1. 사람 모델 1개와 소수의 체형 변형을 준비합니다.
2. 대표 상품 2~3개를 정하고 앞·뒤·옆 사진과 치수를 모읍니다.
3. 기준 체형에 의상을 제작하고 360도 뷰어에서 확인합니다.
4. 체형 변화, 의상 교체와 겹쳐 입기를 검증합니다.
5. 모바일 성능을 최적화한 뒤 상품 수를 늘립니다.

포트폴리오의 스타일링 미리보기와 실제 사이즈 적합도 예측은 구분해야 합니다. 정확한 핏을 주장하려면 실제 상품 치수와 소재, 체형별 검증 자료가 필요합니다.

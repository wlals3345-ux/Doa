DOA UI — Windows 실행 안내

1. ZIP 압축을 풀어 doa-ui 폴더를 만드세요.
2. index.html을 더블클릭하면 브라우저에서 바로 열립니다.
3. VS Code에서는 파일 > 폴더 열기 > doa-ui를 선택하세요.
4. 권장: VS Code 확장 Live Server 설치 후 index.html 우클릭 > Open with Live Server.

설치 또는 빌드가 필요하지 않습니다. HTML/CSS/JavaScript와 로컬 SVG 이미지로 구성했습니다.

구현 화면: 홈, 카테고리별 상품 목록(20개/페이지, 5페이지), 상품 상세,
장바구니, 로그인, 회원가입/완료, 아이디/비밀번호 찾기 시연, 마이페이지,
주문서/시연 완료, 커뮤니티 목록/상세, 아웃핏 작성/수정/삭제, 브랜드 소개.

시연 로그인: demo / demo1234
회원가입 시 실제 개인정보 대신 예시 정보를 사용하세요.
회원가입 비밀번호는 현재 탭 메모리에만 유지하며 저장하지 않습니다.
새로고침 후에는 시연 로그인을 사용하세요.
장바구니/시연 프로필/게시물/시연 주문 내역은 브라우저 localStorage에 저장됩니다.
실제 인증, DB, 결제, 이메일, 알림 전송, Instagram 연동은 제공하지 않습니다.
상품명, 가격, 치수 및 의류 일러스트는 UI용 예시입니다.
이미지 업로드: PNG/JPEG/WEBP, 2MB 이하.

초안의 기능/디자인 요구사항을 참고해 UI를 제작했습니다.
폰트: 설치되어 있는 Inter/Pretendard 우선, 없으면 Windows 기본 폰트 사용.

한국어 / 日本語 전환
- 화면 상단 언어 선택에서 日本語를 선택하면 일본어 UI로 전환됩니다.
- 메뉴, 상품명/안내, 장바구니, 회원가입/로그인, 주문, 커뮤니티 UI 및 예시 게시물을 번역했습니다.
- 선택 언어를 브라우저에 저장하며, 입력 중인 폼과 장바구니는 전환 시 유지됩니다.
- 사용자 작성 게시물/댓글/이름/검색어는 원문을 유지합니다.
- 원화 가격은 유지됩니다. 일본 엔화 환산 기능은 아닙니다.
- i18n.js에 번역 문구가 있습니다. 추가 번역은 이 파일에서 수정하세요.
- 기존 버전을 수정했다면 백업 후 index.html, style.css, app.js를 교체하고 i18n.js를 추가하세요.
- 수정한 내용이 없다면 새 ZIP의 doa-ui 폴더로 전체 교체하는 것이 가장 쉽습니다.

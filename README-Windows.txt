DOA 서버 버전 실행 안내

이 버전은 Java + Spring Boot + MyBatis + MySQL을 사용합니다.
index.html 더블클릭 대신 README.md의 실행 방법을 따라 http://localhost:8080에 접속하세요.
회원·장바구니·게시물·주문은 서버 DB에 저장됩니다. 기존 브라우저 시연 데이터는 자동 이전하지 않습니다.
데모 공용 계정 대신 회원가입 후 로그인하세요.
실제 결제는 연동하지 않습니다. 계정 찾기 메일은 SMTP 설정이 필요합니다.
일본어에서는 ドア 로고가 크게 표시되고 이번 달 발표 환율 평균으로 엔화 표시됩니다.
